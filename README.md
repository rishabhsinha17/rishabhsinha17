### Hi, I'm Rishabh.

I work on LLM serving at Google, and on the open-source inference stack everywhere else. Mostly that means KV-cache management and layout, prefill-decode disaggregation, and the test and transfer infrastructure underneath them.

- Triage collaborator on [kvcached](https://github.com/ovg-project/kvcached), GPU KV-cache virtualization for vLLM and SGLang
- Workgroup member (Evaluation & Quality) in [vllm-project/semantic-router](https://github.com/vllm-project/semantic-router)
- In [Mooncake](https://github.com/kvcache-ai/Mooncake) I wrote the MasterScenario DSL its store tests now run on. In [LMCache](https://github.com/LMCache/LMCache) I'm proposing a declarative KV-layout descriptor.
- Wrote [servetune](https://github.com/rishabhsinha17/servetune), which measures how many GPUs a vLLM or SGLang deployment needs for its traffic and which flags change that number
- Contributions across [SGLang](https://github.com/sgl-project/sglang), [vLLM](https://github.com/vllm-project/vllm), [llm-d](https://github.com/llm-d/llm-d), [TileLang](https://github.com/tile-ai/tilelang), [LLM Compressor](https://github.com/vllm-project/llm-compressor), [NIXL](https://github.com/ai-dynamo/nixl), and [inference-perf](https://github.com/kubernetes-sigs/inference-perf)
